# 三模式系统实施计划

> **ADR 状态**：用户已确认采纳方案 A
> **UI 位置**：场景选择按钮组放在 FlowMode 上方
> **创建时间**：2026-07-20

## 设计摘要

- **目标**：将"自动场景检测"改为"用户显式选择 + 自动检测兜底"的三模式系统
- **三模式**：PPT / Frontend / Backend，平级可选
- **默认**：'auto'（自动检测，向后兼容）
- **问题库**：frontend 45 题 + backend 23 题 + ppt 10 题（新建）

## 实施步骤（按依赖顺序）

**文件**：`src/question-bank/bank-ppt.yaml`（新建）

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| PPT 问题库覆盖不全 | 每题 allow_custom: true |
| UI 两组按钮拥挤 | 场景组用更小字号，视觉层次区分 |
| 用户选 PPT 但输入前端需求 | 保留 LLM 分析，冲突时提示 |
| schema.json 更新遗漏 | 步骤 2 同步更新 |
