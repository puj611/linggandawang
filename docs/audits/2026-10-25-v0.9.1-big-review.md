## 1 问题清单（严重度降序；✅=已修复）

### [高][B·依赖] 生产依赖链携带 1 critical + 3 high CVE —— **未修（0.9.2 主卡）**
- **位置**：`package.json` → `@xenova/transformers@2.17.2` 传递链
- **证据**：`npm audit --registry=https://registry.npmjs.org`：`protobufjs@6.11.6 [critical, CVE-2023-36665 原型污染]`、`onnxruntime-web@1.14.0 / onnx-proto / @xenova/transformers [high]`、`sharp@0.32.6 [high，浏览器侧不加载]`（`npm ls` 实证全部经 transformers 引入）；Mimosa 依赖 offline advisory 匹配一致（5 包 15 条）
- **触发路径**：运行时从 huggingface.co 拉取 .onnx 模型 → protobufjs 解析；CSP 已放行该域；WebView 持有 Tauri IPC，污染影响面大。前提是模型源投毒（信任 HF 仓库，概率低）
- **修复建议**：迁移 `@huggingface/transformers` v3（protobufjs 7 + 新 onnxruntime，API 有破坏性变更，需嵌入功能回归）；短期 npm overrides 强升 protobufjs@7（需验证 onnx-proto 兼容）。**成本中**

### [高][B·数据丢失] 覆盖导入的自动备份 fail-open —— ✅ **已修（b6539ea #2）**
- 原问题：`backupCurrent` 配额满仅 console.warn 后继续 → overwrite 清空后不可回退
- 修复：备份返回落盘成败，**overwrite 备份失败即中止**并提示先手动导出；merge 增量不销毁保持尽力备份。回归用例：模拟配额满 → 中止且数据原样

### [中][B·幂等] merge 导入无去重 + 导入按钮无防抖 —— ✅ **已修（b6539ea #3）**
- 修复：历史按 `(title, created_at)` 去重；DataPanel `importing` 态禁用。用例：同 bundle 两导 `historyInserted` 第二次为 0

### [中][B·一致性] 模板更新时 created_at 双路径分歧 —— ✅ **已修（b6539ea #4）**
- 修复：SQLite 路径 `INSERT … ON CONFLICT(id) DO UPDATE` 保留 created_at，与 localStorage 对齐

### [中][C·规范] 未跟踪的 setTimeout 违反项目铁律 —— ✅ **已修（b6539ea #5）**
- 修复：`closeTimerRef` 跟踪 + 卸载 cleanup

### [中][E·架构] 分层约束字面与代码现实漂移 —— **未修（待用户决策）**
- AGENTS「UI 不直接调 engine/lib」vs TemplateLibrary/DataPanel 直连 lib（既有先例 SettingsPanel→sqlite.setPreference）
- 二选一：① 修订 AGENTS 承认「UI 可调只读类 lib，写操作走 hooks」（成本低）；② 严格化新增 hooks 封装（成本中）

### [低][B·纵深] 导出密钥过滤仅按键名 —— ✅ **已修（b6539ea #7，超范围加固）**
- 修复：键名 + 值形状（sk-/ghp_/AKIA）双向扫描。用例：键名无辜值含密钥形状 → 不进导出包
